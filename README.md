# 🧠 Simple Quiz

Simple Quiz é um projeto desenvolvido com fins de prática, simulando um quiz simples de perguntas e respostas, renderizado com React.

🔗 **Acesse o projeto**: [simplequiztrainapp.netlify.app](https://app.netlify.com/sites/simplequiztrainapp/overview)
